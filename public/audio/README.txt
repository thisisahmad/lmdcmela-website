Put the hero player's songs here (MP3, 128-192 kbps keeps them small), e.g.
  joona.mp3, aarzu.mp3, peechay-hutt.mp3, sun-le-na.mp3
Then set `src` for each song in src/config.js -> playerTracks, e.g. src: '/audio/joona.mp3'.
Only upload songs you have permission to use.
Files are cached for a year: when replacing a song, give the file a NEW name.
